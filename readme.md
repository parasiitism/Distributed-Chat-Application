Multiclient Distributed Real-Time Chat Application (Python)

A horizontally scalable, real-time, room-based chat application supporting unicast, multicast, and broadcast messaging.
The system is designed as a distributed backend platform, capable of handling multiple backend instances with consistent real-time behavior.
